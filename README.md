# FastAPI backend to support Rag

## Features
- File upload
- File processing
- Semantic searching
- LLM Response generation

## Imp path
- `http:localhost:8000/docs`

## Imp commands
- format code
```bash
ruff format 
```
- lint code
```bash
ruff check 
```
- Start dev Server
```bash
uv run fastapi dev main.py
```
